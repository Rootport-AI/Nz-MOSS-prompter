Nz-MOSS-prompter (Windows x64 ポータブル版)
================================================================

■ 起動方法
1. 本 ZIP ファイルを任意のフォルダへ展開してください。
2. 展開された「Nz-MOSS-prompter.exe」をダブルクリックして起動します。
   ※ インストーラーおよび管理者権限は不要です。

■ オフライン動作・プライバシー
Windows版Nz-MOSS-prompterは、プロンプトの編集・保存をローカル環境内で行います。入力内容を外部サーバーへ送信する機能は搭載していません。

■ 動作環境
- Windows 11 (x64)
- Microsoft Edge WebView2 ランタイム（Windows 11 には標準搭載されています）
  ※ 万一起動時にエラーが表示される場合は、Microsoft 公式の WebView2 ランタイムをインストールしてください。

■ 初回起動時の Windows SmartScreen 警告について
本アプリはコード署名を行っていないため、初回起動時に
「Windows によって PC が保護されました」と表示される場合があります。
内容をご確認のうえ、「詳細情報」→「実行」を選択して起動してください。

■ データの保存先・移行・削除
- 保存先:
  %LOCALAPPDATA%\io.github.rootport-ai.nz-moss-prompter\EBWebView\
- 同一 Windows ユーザー内であれば、ZIP 展開フォルダを移動したり新バージョンへ
  差し替えたりしても、編集中のデータとテーマ設定は自動的に引き継がれます。
- 別の PC へのデータ移行や Web 版とのやり取りには、アプリ内の JSON Export / Import
  機能をご利用ください。
- 完全に削除する場合は、展開したフォルダと上記保存先フォルダを削除してください。
